# Intra Decor Home (FYP)

A home decor marketplace website where customers can buy wallpapers, tiles, wall panels and paint, preview products on a room using AI, try wall colors with the Paint Visualizer, and book service providers.

**Roles:** User, Seller, Service Provider, Admin
**Built with:** PHP, MySQL, HTML, CSS, JavaScript, PHPMailer, Safepay (sandbox), Python AI API on PythonAnywhere
**Live hosting:** InfinityFree

## Setup
1. Import `database.sql` into MySQL.
2. Put your database details in `db.php` and `sellerdashboard/db.php`.
3. Put your Gmail app password in `mailer.php` and Safepay keys in `safepay/config.php`.

Passwords and keys are removed from this repository for security.
